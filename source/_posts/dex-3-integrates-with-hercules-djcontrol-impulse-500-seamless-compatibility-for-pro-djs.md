It’s equipped with two high-resolution jog wheels and 16 RGB-backlit pads, a Filter/FX section, a built-in audio interface and hardware input mixer with a full array of I/O, including a microphone input with High EQ and Low EQ knobs for tone-sculpting (which lends itself nicely to those that use [DEX 3 for hosting karaoke](https://tools.techidaily.com/pcdj/products/)). You also get an aux input with add “ear-grabbing filter effects”. The retractable/extendable feet provide easy cable routing and protect against spilled drinks (also a big plus for KJs!).

The DJControl Inpulse 500 would be a great fit for mobile DJs using DEX 3, and compares favorably to other 2-deck [DJ Controllers](https://tools.techidaily.com/pcdj/products/) at an attractive price-point of only $299 on most DJ equipment websites.

**DJ CONTROLLER MAP INSTALLATION INSTRUCTIONS:**

* For DEX 3 Version 3.14 and Above: Open up DEX 3 and go into options. Under the General Tab in option click the “Data Folder” button to open up the PCDJ-DEX3 folder. Close DEX 3\. Unzip the Js map file and place it in the Controllers folder within the PCDJ-DEX3 data folder. Start DEX 3 with the DJ Controller connected and it will be picked up by DEX 3.
* For DEX 3 RE (Red Edition) Unzip the Map (js file ONLY in zip) To: DOCUMENTS -> PCDJ-RED3 -> CONTROLLERS

**After installation, go into DEX 3 RE/DEX 3’s options and under the “Audio Routing” tab apply this configuration:**

* From Select Audio Device, Select the Hercules ASIO option.
* Deck A through D: 1+2
* Headphones 3+4
* All other options can be set to none/no audio (including additional headphone/preview device).
* Do NOT put a tick in the box for external mixer mode.
* That will provide the proper audio routing for headphone pre-fade listening (cue)
